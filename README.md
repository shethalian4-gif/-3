2. Задали исходные данные: интервал изменения аргумента от \(x=0{,}1\) до \(x=1{,}0\), количество интервалов \(m=10\), количество членов ряда \(n=10\) и точность вычислений \(\varepsilon=0{,}0001\).

3. Записали математическую формулу разложения функции в степенной ряд:
\[
3^x=e^{x\ln 3}=\sum_{k=0}^{\infty}\frac{(x\ln 3)^k}{k!}.
\]

4. Подключили необходимые библиотеки C++ для ввода и вывода данных, форматирования результатов и выполнения математических операций.

6. Организовали цикл for для последовательного вычисления значений аргумента \(x\) на заданном интервале.

7. Вычислили сумму первых десяти членов степенного ряда, используя рекуррентную формулу для определения каждого следующего члена.

8. Вычислили сумму ряда с заданной точностью \(\varepsilon=0{,}0001\), используя цикл do-while и проверку величины очередного члена ряда.

9. Вычислили точное значение функции \(y=3^x\) с помощью стандартной функции pow().

10. Вывели результаты вычислений в виде таблицы, содержащей значения аргумента \(x\), сумму ряда при фиксированном количестве членов \(S_N\), сумму ряда с заданной точностью \(S_E\) и точное значение функции \(y\).

11. Сравнили полученные результаты и проанализировали точность вычислений.

12. На основании выполненной работы сделали вывод о применении циклов и степенных рядов для приближённого вычисления значений математических функций.
